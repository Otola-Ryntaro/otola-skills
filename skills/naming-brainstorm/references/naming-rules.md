# 命名ルール詳細

このスキルが従う命名の基準・名前の型・許容パターン・避けるべきパターンをまとめる。

---

## 基本ルール

### 文字数・音節

| 言語タイプ | 基準 |
|------------|------|
| 日本語ひらがな | 省略形で **3文字 or 4文字** |
| 日本語カタカナ | 省略形で **3文字 or 4文字** |
| 英語 | 省略形で **1音節 or 2音節** |
| 日英ハイブリッド | 日本語側 3〜4文字 / 英語側 1〜2音節 のいずれかを満たす |

> **「省略形」とは**: コンセプトを表す既存単語・造語の素材から削ぎ落とした形のこと。「コンビニエンスストア → コンビニ」のような短縮が典型。

### 大前提

- **覚えやすい**: 一度聞いて翌日も思い出せる
- **言いやすい**: 母音子音の流れが自然で噛まない
- **書きやすい**: 綴りが直感的で、聞いただけで書ける
- **口頭で伝わる**: 電話・対面で伝えてもスペルを聞き返されにくい

## 名前の型（バラエティの軸）

候補を発散する時に、以下の **5つの型** をまたいで出す。型ごとに 4〜6 個ずつ出すと多様性が安定する。

### 1. 機能型

サービスの機能・対象を直接含む。意味が伝わりやすいが、独自性は弱い。

- 例: メドチズ（医療＋地図）/ カルナビ（カルテ＋ナビ）/ コエヨミ（声＋読み）

### 2. 感情型

ユーザーが感じる感情・体験を直接表す。親しみやすいが、サービス内容が分かりにくいことがある。

- 例: あんしん / よりそい / ほっと / すこやか

### 3. 造語型

既存単語の合成・音の遊びで作る。独自性が高いが、意味が伝わりにくい場合は説明が必要。

- 例: メドリス / チズカ / Glanz / Notion

### 4. 比喩型

サービスの本質を別のモノで例える。記憶に残りやすく、ストーリーが作りやすい。

- 例: コンパス（道案内）/ ルーペ（拡大して見る）/ Slack（時間を緩める）

### 5. 専門略語型

業界用語・英単語の略。専門家向けに信頼感を出せる。

- 例: ClinMap（Clinical + Map）/ MedNav（Medical + Navigation）/ FinTrack

## 許容パターン

### ハイブリッド型（表記と読みのズレを活用）

日本語と英語の境界をまたぐと、覚えやすさと検索性を両立しやすい。

| 表記 | 読み | 解説 |
|------|------|------|
| `nico` | ニコ | 短い英語綴り × カタカナ2音 |
| `Glanz` | グランツ | ドイツ語語源 × カタカナ4音 |
| `Yuyu` | ユーユ | 繰り返し音で覚えやすい |
| `Kuma` | クマ | 日本語そのまま × ローマ字 |
| `Hover` | ホバ | 英単語短縮 × カタカナ3音 |

### 繰り返し・押韻パターン

- 同じ音の繰り返し: `Lulu` / `Momo` / `Pepe`
- 母音をそろえる: `Sara` / `Kira` / `Mira`

→ かわいい・親しみやすいトーンに合う。B2C 向き。

### 子音 + 母音の最小構成

- 2音節英語: `Slack` / `Notion` / `Figma` 級の覚えやすさ
- 3文字カタカナ: `ココ` / `カラ` / `モグ`

→ シンプル・モダンなトーンに合う。

### 造語の作り方パターン

- **頭文字 + 末尾**: Quickly + Reply → `Qly`（クリィ）
- **意味 + 意味**: 「みえる」+「かんたん」→ `mican` ※既存衝突注意
- **母音差し替え**: `Memo` → `Memu`
- **語尾調整**: `-o` / `-a` / `-i` で響きを変える（`Vizo` / `Viza` / `Vizi`）

## 攻め案 / 無難案 / 本命案 の分け方

10候補は同じ温度感だと選びにくい。以下のように振り分けると意思決定しやすい。

| 区分 | 性格 | 出すべき型 |
|------|------|------------|
| **無難案** | 信頼感があり外しにくい | 機能型・専門略語型 |
| **親しみ案** | 親近感がありユーザーに刺さる | 感情型・繰り返し音 |
| **攻め案** | 挑戦的・印象に残る | 造語型・比喩型 |
| **本命案（1〜3個）** | 7軸スコア総合トップ | 型横断、ヒアリング方針に最も合うもの |

10個の内訳の目安: 無難3 / 親しみ3 / 攻め2 / 本命2（重複可、本命は他区分から選ばれる）。

## 避けるパターン

### 発音困難

- 子音の連続が3つ以上: `strngth`、`Schwftz` のような綴り
- 日本語話者が苦手な音の連続: `th` + `r`、`l` + 母音 + `l` など
- ローマ字読みと英語読みが大きく食い違う: `Kaiji` を「カイチ」と読まれる等

### 既存大手と紛らわしい

- 大手サービス名と1音違い: `Slack` に対する `Slock` など
- 大手ブランドの音を踏襲: `Apll`、`Goog` などは却下

### 多言語スラング衝突

特に以下の言語圏で意味を持つ場合は要警戒（Phase 5 の WebSearch で必ず確認）:

- 英語スラング
- スペイン語（中南米市場でメジャー）
- ドイツ語
- 中国語（標準語・広東語の発音）
- 韓国語
- フランス語
- ポルトガル語（ブラジル市場狙うなら）

### 検索しづらい

- 一般名詞そのもの: `Apple`、`Book`、`Cloud` 等は検索ノイズが多すぎる
- 数字との混同: `4Sale`、`B4` などは口頭で誤解されやすい

### 商標リスクが高い

- 特定業界の大手商標と類似（J-PlatPat や商標サイトで衝突確認推奨）
- 著名人・キャラクター名と同一/酷似

### ターゲット領域に合わない響き

- 医療・教育・金融などの **信頼性が重要な領域**: 軽すぎる名前・怪しい響き・カジュアル過ぎる造語を避ける
- 子ども向け: 専門用語・難読語を避ける
- B2B エンタープライズ: かわいすぎる響きは避ける

## トーン別の傾向

ヒアリングで聞いたトーンに応じて、候補の比重を変える。

| トーン | おすすめ系統 |
|--------|--------------|
| カチッと信頼感 | 1〜2音節英語、ラテン語/ドイツ語由来、子音強め、専門略語型 |
| かわいい親しみやすさ | 繰り返し音、3文字カタカナ、ひらがな、感情型 |
| クールでモダン | 短い英語綴り、造語、ハイブリッド、比喩型 |
| 遊び心 | 擬音語・擬態語、ひらがな、ハイブリッド |
| 専門性・知性 | ラテン語/ギリシャ語語源、専門略語型、比喩型 |

## 候補を出す時に併記すべき情報

候補1つにつき以下を必ず示す:

- **名称**
- **表記案**（ローマ字 / カタカナ / ひらがな / 英語など複数あれば併記）
- **読み**（カタカナ）
- **由来**（短く、1〜2行）
- **向いている理由**（強み）
- **懸念点**（弱み）
- **名前の型**
- **5段階総合評価**

ハイブリッド表記の場合は、「日本人にこう読まれる」「英語ネイティブにこう読まれる」を両方併記すると親切。
