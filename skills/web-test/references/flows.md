# プロジェクト固有フロー・URL契約

このファイルは雛形です。対象プロジェクトの URL と認証に合わせて書き換えてください。

## URL パターン

| ステップ | URL | 説明 |
|---------|-----|------|
| トップ | `/` | 公開ページ |
| ログイン | `/login` | 認証画面 |
| ダッシュボード | `/dashboard` | ログイン後のメイン画面 |
| 設定 | `/settings` | 管理者向け設定 |

## 認証パターン

| ロール | 認証方式 | 備考 |
|--------|---------|------|
| 訪問者 | 認証なし | 公開ページのみ |
| ユーザー | メール + パスワード | テスト用アカウントを使う |
| 管理者 | パスワード + MFA | 本番では実行前にユーザーへ確認する |

## 自然言語 → ステップ変換の例

### 例1: 「ログインからダッシュボードまで確認」
```
1. /login にアクセス
2. テスト用アカウントでログイン
3. /dashboard の表示を確認
```

### 例2: 「設定画面を確認」
```
1. 管理者でログイン
2. サイドバーから「設定」をクリック
3. 項目の表示と保存を確認
```

## テスト用データの確認方法

1. プロジェクトの README やシードデータを確認する
2. 不明な場合はユーザーに質問する
