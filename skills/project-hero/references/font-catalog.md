# font-catalog — 書体候補プール

3 案提示時は**異なる系統**から 1 つずつ選ぶ。used-fonts.md に記録済みの書体は
デフォルト候補から除外する（ユーザー明示指定時は再利用可）。
URL は `https://fonts.googleapis.com/css2?family=<Family+Name>:wght@700&display=swap` 形式で組む。

| 系統 | 印象 | 候補 |
|------|------|------|
| Display / Expressive | 個性的・攻め | Bricolage Grotesque, Clash 系代替: Unbounded, Anton, Bungee, Monoton |
| Geometric Sans | モダン・テック | Space Grotesk, Outfit, Sora, Manrope, Urbanist |
| Serif / Editorial | 信頼・知的 | Playfair Display, Fraunces, Newsreader, Lora, Cormorant Garamond |
| Slab / Retro | 骨太・道具感 | Zilla Slab, Alfa Slab One, Chivo, Archivo Black |
| Mono / Terminal | CLI・開発者向け | JetBrains Mono, Space Mono, IBM Plex Mono, Fira Code |
| Handwritten / Soft | 親しみ・実験 | Caveat, Kalam, Gochi Hand, Shantell Sans |
