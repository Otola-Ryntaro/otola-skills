# 中締め（/nakajime）

セッションを一時中断するときの軽量な状態保存。

## 実行手順

### Step 1: 現在地の把握

会話履歴から以下を簡潔に整理する：

- **今やっていること（WIP）**: 途中の作業
- **次のアクション**: 再開したらまずやること
- **ブロッカー**: 詰まっていること（あれば）

### Step 2: Plans.md に現在地を記録

Plans.md の末尾に以下を追記する。Plans.md が存在しない場合は新規作成。

```markdown
## 中断メモ（YYYY-MM-DD HH:MM）

### 作業中（WIP）
- 

### 次のアクション
1. 

### ブロッカー（あれば）
- 
```

### Step 3: 完了メッセージ

```
中断メモを Plans.md に保存しました。
再開時は「前回の続き。Plans.md を確認して」と言えばすぐ再開できます。
```

---

## 注意事項

- 日報は作成しない（日報が必要な場合は `/shime` を使う）
- 5行以内で簡潔に。詳細より「再開のスタート地点」を明確にすることが目的
